## 玩家操作

启动发布版 `wendao.exe`，或在开发机用 `go run ./cmd/wendao`。玩家不需要为发布版安装Go。程序需要交互式终端；重定向输入/输出时会拒绝进入游戏，不创建用户数据目录。游戏进度写入当前Windows用户的本地应用数据目录，界面设置使用独立文件。

输入一项后按回车，每次只解析一个可打印字符。将`1 2`或多项菜单键粘贴进去只会提示忽略，不会连续执行动作。支持的按键如下：

| 页面 | 按键 | 行为 |
|---|---|---|
| 创角 | `1`、`2`、`3` | 选择三种合法开局预设，并保存创角草稿；不推进月份 |
| 创角确认 | `c` | 创建角色并进入洞府；不推进月份 |
| 创角确认 | `b` | 返回预设页 |
| 创角确认 | `e` | 打开身份资料编辑；再按`1`姓、`2`名、`3`道号、`4`性别、`5`外观、`6`年龄 |
| 文本编辑 | 输入一行后按回车 | 保存到创角草稿；`q`是字段内容，`年龄`限16～60；输入`:cancel`取消本次编辑 |
| 游戏主屏 | `1` | 普通修炼一个月；提交成功后立即保存，并显示修为变化 |
| 游戏主屏 | `d` | 查看角色详情；`n`/`p`分页，`b`返回 |
| 游戏主屏 | `i` | 查看背包；`n`/`p`分页，`b`返回 |
| 任意页面 | `h` | 查看帮助（子页按`b`返回） |
| 游戏主屏 | `s` | 打开界面设置：`t`切换主题、`c`切换颜色档、`m`切换静音偏好、`b`返回 |
| 任意页面 | `q` | 正常退出，保留最近完整提交 |
| 任意页面 | Ctrl+C / EOF | 结束会话；未完成的输入不执行，不推进月份 |

所有实际游戏行动和创角资料编辑同步提交存档，TUI不会在后台重放命令。重启会显示恢复提示和最近行动账本。文本字段检查UTF-8、控制字符和长度；年龄限制为16～60。遇到保存失败，界面锁住游戏行动，仅允许安全退出；设置写失败不会损坏角色存档。设置损坏时使用安全默认值。游戏没有发声代码，静音偏好不会产生终端响铃。

## 布局与终端行为

- 标准画面展示标题、游戏月份、境界与生命状态、修为进度条、灵石、当前场景、最近变化、保存状态和可用键。
- 事件与突破的展示模型保留逐项代价/风险；未实现的事件和战斗只在渲染自动化测试中用fixture验证，不会伪装成真实游戏内容。
- 80×24、64×20和48×16按可用高度裁撤历史与可选详情；可操作选项和保存状态受保护。小于48×16时提示扩大窗口，只接受`q`。
- TUI每500毫秒检查一次终端尺寸。缩放后重绘但不提交命令；如果输入到达时检测到尺寸刚变化，则丢弃该输入并按新尺寸重画。
- 自动检测真彩、256色或16色；用户可切换自动/16色/无色。ANSI输出只在终端支持时启用，并在退出时复位颜色及恢复原有Windows控制台输出模式。输入保持系统行缓冲与回显，不隐藏光标、不进入备用屏幕、不请求焦点。
- 不写工作任务的标准输入/输出，不读取工作进程，不联网、不扫描仓库，也不按现实时间推进。
