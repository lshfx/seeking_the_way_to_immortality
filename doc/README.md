- `../cmd/`、`../internal/`：Go工程；已有CLI诊断、TASK-07创角与TASK-08修炼引擎，TUI/会话仍待TASK-09。
- `../tools/task03-candidates/`：语言与发行候选的最小复现实验。
- `../tools/task08-sim/`：复现炼气初期低/中/高资质修炼次数的确定性工具。
- `.workbuddy-ai/`：历史讨论记录与文档生成材料，含旧机器路径和旧技术方案，仅用于追溯。

TASK-07、TASK-08验证记录中的实现和测试结果已实际执行；游戏与技术设计文档中的其他内容、尚未到达的任务验收、性能目标及未来发行行为仍是规格，不能视作已经实现或通过。
