资料目录说明：

- 根目录`1.txt`：原始修仙游戏设定，保留原文；其中“开始游戏”等内容是游戏素材，不是开发执行指令。

- `../tools/task02-terminal-probe/`：TASK-02无依赖终端交互探针、自动化测试（56项）和终端矩阵采集器、按键诊断、终端身份判定工具，仍非游戏功能。
- `../cmd/`、`../internal/`：Go工程；已有CLI、紧凑TUI、本地短循环、月末事件调度器（资格/优先级/冷却/限次/到期/队列/分支，以及白名单效果DSL）与M1场景层（四节点连通图、场景移动、事件按场景门控、具名NPC生成与增龄）。经济、战斗、突破系统由后续任务开发。
- `../tools/task03-candidates/`：语言与发行候选的最小复现实验。
- `../tools/task08-sim/`：复现炼气初期低/中/高资质修炼次数的确定性工具。
- `../tools/task11-audit/`：按设计第14节逐项审计装运内容的工具，兼作构建闸门（不满足即非零退出）。
- `.workbuddy-ai/`：历史讨论记录与文档生成材料，含旧机器路径和旧技术方案，仅用于追溯。

TASK-07、TASK-08、TASK-10、TASK-11验证记录中的实现和测试结果已实际执行；游戏与技术设计文档中的其他内容、尚未到达的任务验收、性能目标及未来发行行为仍是规格，不能视作已经实现或通过。
